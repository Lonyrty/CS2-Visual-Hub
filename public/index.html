03 / Build your visual

Редактор постеров.

Управляй типографикой и цветом. Результат можно сохранить как SVG и использовать в своих проектах.

EXPORT / SVG

OUTPUT PREVIEW / 1200 × 900

Векторный файл можно масштабировать без потери качества и открыть в браузере или графическом редакторе.

Desktop companion / Windows

Visual Hub.
За пределами браузера.

Компактное настольное приложение с быстрым отдельным окном. Открывай его клавишей F8 и скрывай через Esc. Приложение не внедряется в процесс CS2 и не меняет игровые файлы.

Windows 10 / 11Для настольного ПК
F8 / EscПоказать / скрыть окно
StandaloneОтдельное приложение
WINDOWS INSTALLERCS2 Visual Hub Setup.exe

Если новая сборка ещё не опубликована, ссылка может временно не работать. Последняя доступная версия появится в релизах GitHub.
