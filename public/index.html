08 / Desktop companion · Windows

Visual Hub.
За пределами браузера.

Компактное настольное приложение с быстрым отдельным окном. Открывай его клавишей F8 и скрывай через Esc. Приложение не внедряется в процесс CS2 и не меняет игровые файлы.

F8 / EscПоказать / скрыть окно
